# 👑 Happy Birthday Queen Iris! 🎉

A interactive, responsive birthday quest and digital memory vault built specially for **Queen Iris Angeline Crisostomo**. The project takes the user through an emotional text intro, an engaging mini-game challenge, and rewards them with a personalized photo gallery complete with a hidden "final boss" video surprise.

## 🚀 Live Demo
Check out the deployed site here: **[Click Here!](https://iris-birthday.onrender.com)**

---

## 🎮 Features & Interactive Stages

* **Stage 1: Emotional Intro Timeline** – A smoothly timed typographic display that shares heartfelt, funny, and nostalgic memories of friendship (complete with a progress bar).
* **Stage 2: The Birthday Quest Game** – A custom, lightweight interactive catch-falling-items canvas game. The player must collect 10 birthday treats to unlock the prize vault. Fully optimized for both desktop cursor movement and mobile touch interactions.
* **Stage 3: The Memory Vault** – A beautifully animated grid showcase featuring iconic, funny, and unforgettable moments, styled with native image expansion modals (Lightboxes) for close-up viewing.
* **Stage 4: The Final Boss** – A custom modal containing an iconic final video masterpiece that plays seamlessly upon dismissal.
* **Theming** – Wrapped in a premium, responsive glassmorphism layout with customizable thin, theme-matching cyan scrollbars.

## 🛠️ Tech Stack & Resources

* **Markup:** HTML5
* **Interactivity & Logic:** Vanilla JavaScript
* **Styling & Layout:** Tailwind CSS v4 CDN & Custom Native CSS overrides
* **Typography:** Fredoka & Quicksand via Google Fonts
* **Deployment Platform:** Render (Static Site Hosting)
